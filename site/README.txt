PORTFOLIO PROFESSIONNEL — NADHIR JLASSI
=======================================

CONTENU
- index.html : site et sections du dossier professionnel
- style.css : design responsive (thème Navy / Teal / Gold)
- script.js : navigation mobile et aperçu agrandi des images
- assets/ : photos, attestations, certifications et documents PDF

LIVRABLES AJOUTÉS
1. diagnostic-personnel.pdf
2. CV_Nadhir_Jlassi (1).pdf : première maquette conservée pour comparaison
3. CV_Nadhir_Jlassi_V2.pdf : CV actuel de référence
4. lettre-motivation-version-ia.pdf : première proposition de lettre
5. lettre-motivation-personnalisee.pdf : lettre personnalisée à adapter à chaque entreprise
6. comparaison-cv-et-justification.pdf : explication des modifications du CV
7. veille-professionnelle-offres-tunisie.pdf : synthèse d'offres consultées le 24/11/2026

SIMULATION D'ENTRETIEN
La vidéo n'est pas intégrée au site. La section correspondante explique qu'elle sera présentée directement à l'enseignant en privé. La grille d'auto-évaluation est préparée, à compléter après la simulation et selon la grille collective du cours.

OUVRIR LE SITE
1. Extraire le dossier.
2. Ouvrir index.html avec Chrome, Edge, Firefox ou Safari.
3. Garder index.html, style.css, script.js et le dossier assets ensemble.

METTRE À JOUR GITHUB
Depuis le dossier du projet :
  git add .
  git commit -m "Ajout des livrables du dossier professionnel"
  git push origin main

IMPORTANT
Les liens des offres renvoient vers les annonces originales. Les annonces peuvent changer ou expirer. Ajouter au dossier de remise des captures d'écran datées des annonces consultées, si l'enseignant les exige.
La lettre personnalisée contient des champs à adapter (entreprise, destinataire, période) avant envoi.
